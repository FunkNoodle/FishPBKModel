This repository contains the R version of the Fish PBK model developed by Wang et al. (2022) at Radboud University. The model was converted to an R script by Davey at al. (Radboud) on behalf of the PREMIER project (https://imi-premier.eu/).

The R script is suposed to be run in batches, and both R scripts and the input CSV need to be in the project folder when running the model. Please read the model instructions to see how to run the code.
